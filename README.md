# Wincy Li · 个人作品集

在线主页：https://wincyli.github.io/

纯静态 HTML / CSS / JavaScript，由 GitHub Pages 发布。

## 页面结构

- `index.html`：个人介绍、四项优势、五个精选作品、联系入口。
- `about.html`：实习经历、教育背景、工具与表达能力。
- `projects/`：三个 AI 运营案例、两部 AI 短片的独立详情页。
- `assets/work/`：作品集节选图片与短片封面。
- `assets/video/`：网页播放版本的短片；保留原始素材在本地，不上传原始 MOV。
- `styles.css` / `script.js`：响应式样式、作品筛选、图片放大。

## 内容维护

新增作品时同时更新首页卡片与对应详情页。工作经历与指标以经确认的简历为准；区分个人职责和团队成果，不推断业务提升比例。课程中心展示的是资源整理工作，不将第三方课程当作原创成果。

公开仓库中不放原始简历 PDF、完整作品集 PDF、私人电话号码、内部文件、同事照片或账号信息。页面内的工作样例为选取后的内容节选。

视频不自动播放，也不在首页预加载。页面保留 TapTV 个人主页入口。

## 本地预览

在仓库目录运行 `python3 -m http.server 8765`，然后打开 `http://127.0.0.1:8765`。修改后检查桌面、平板和手机宽度，确认相对链接、图片及视频正常，再推送到 main。
